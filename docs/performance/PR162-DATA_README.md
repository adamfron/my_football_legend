# PR162 evidence and data retention

The main experiment is measured at frozen public source `86673d5fe3752efc6008cbd56b4e9ed048faafda`: 120 full matches, including its unchanged 30-match pilot. The late threat-memory physical-origin validation patch is source `e652c31113fe3406d5198c6660811ebd820d8c99`; its complete-state parity is reported separately. No matrix result is relabelled to that later source.

Public review data:

- `PR162-summary.json`: numerical pilot/main/native/baseline summaries, raw orientation outcomes and paired seed-block distributions. Censored baseline status remains explicit.
- `PR162-EVIDENCE_TABLES.md`: formation, attack funnel, forward gap, role networks, progression, goalkeeping, turnovers, observed ground-challenge foul zones, shape, rankings, controlled comparisons, matched native-club comparisons and conditional conversion tables.
- `PR162-SENSITIVITY_TABLES.md` and `PR162-sensitivity-summary.json`: bounded ability/duty experiments and matched onside requested-shot probes. Requested shots are not initial NPC selection evidence.
- `PR162-club-profiles.json`: role attribute means, effective role quality, three distinct squad-rating projections, condition and native coach formation/style defaults. Individual player identities/profiles are omitted from public data.
- `PR162-baseline-manifest.json`, `PR162-baseline-funnel-v1.ts.txt`, `PR162-source-revisions.json`: source provenance, historical observer definition and exact Git-tree equivalence.
- `PR162-funnel-validation.json`, `PR162-observer-parity.json`, `PR162-schema-parity.json`, `PR162-telemetry-reference.json`, `PR162-performance.json`, `PR162-restart-recovery.json`: accounting, complete-state identity, all-field telemetry repeat receipts, limited headless timing and frozen-restart recovery receipts.
- `PR162-controlled-summary.json`: all 27 scenarios on each revision, with numerical geometry/readiness/opportunity and actual outcomes.

Complete compact records remain in the local `PR162-wyniki-benchmarkow.zip` deliverable: deduplicated full generated profiles, bounded action/spatial traces, full initial requested-shot states, two preserved actual restart states, all 80-field telemetry payloads, and the unmodified original baseline benchmark. No user session export, environment files, credentials or raw per-tick trajectory archive is included. Each retained file has a SHA-256 inventory.

Automatic publication review rejected the larger complete benchmark archive. The PR publishes a smaller numerical review dataset; complete records are available locally for inspection and replay. Their upload would require separate explicit approval. This retention distinction is material: readers cannot obtain the frozen restart states or complete generated profiles from the Git repository alone.

The baseline's six censored runs are neither full matches nor draws. Invalid V1/V2 shot-stage intersections are null in derived evidence; the original baseline is retained without rewriting its counters. The full main archive is reproducible at its frozen source using the documented CLI; snapshot replay additionally requires the local archive. Missing advanced mechanisms remain unknown, not zero.
