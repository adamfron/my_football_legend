# PR198 evidence

The [report](../../PR198_RECEIVER_SYNCHRONISATION_AUTONOMOUS_OPPORTUNITIES_AND_EMERGENT_DISRUPTION.md) and [summary](summary.json) identify the selected cohorts. All data is development evidence; independent confirmation remains sealed, canonical NOT READY and B default.

- `frozen-pr197.json`: merged source fingerprint, all 134 historical IDs/statuses and immutable PR195–197 Git blob identities.
- `releases-v1.json.gz`: 180 exact actual PR197 releases plus 40 rejected requests, complete released states, launched-ball hashes, seeds, receiver bodies and original-delivery-v3 lineage.
- `receptions-*-v1.json.gz`: all eight D/H/R ablations. `synchronized-v1` is the rejected prototype (129/102/91); `synchronized-v2` is the final optional controller (149/113/108, below combined 154/123/116).
- `sensitivity-v2.json.gz`: selected 448 initial-condition trials. `v1` is retained exploratory apparatus evidence.
- `opportunities-*-v2.json.gz`: two 280-case standing-runner cohorts. Sparse menu counts are 55→152; actual decision witnesses add 24 short windows, producing 55→176 by either witness. Five autonomous releases do not complete the desired deliberate-run chain. The summary preserves both measurement views.
- `disruption-v3.json.gz`: final 132 paired shot/pass/hold, pressing, clearance and real centre-back carry requests, with actor paths and the negative counterattack case. `v1`/`v2` preserve exploratory measurement revisions; final turnover attribution retains prior ownership through a loose interval and excludes owned carry touches from unowned deflections.
- `rebounds-v1.json.gz`: 64 original shots, including two real original-shot keeper contacts with an unowned outgoing ball; all negative outcomes retained.
- `performance-*-v2.json`: one serial profile process and two concurrent profile processes on identical actual observations; deterministic output hashes match. Wall, CPU and RSS are separate; other work competes on the host. `v1` is retained before explicit two-pass sample-budget labelling.
- `matches/*-v2.json.gz`: fourteen complete paired matches. The first three observer revisions are superseded for measurement by `*-observer-v3.json.gz`; those three whole replays require identical initial/final physical hashes and ticks. All original receipts remain. Interrupted prototype `v1` prefixes are not complete matches and are not selected.
- `source/`: normalized complete manifests plus exact deltas over merged PR197. Fingerprints identify measured code, not Git revisions. Check mode reconstructs and verifies these archives before read-only comparison.
- `verification.json`, `verification-v1.json`, `verification/v1/`: actual local command results and compressed logs, including initial failures and successful reruns. Remote CI must be checked separately on the final PR head.
- `concurrency-v2.json`: coordinator wall time and fourteen child exits; separate from per-child CPU, per-process peak RSS and observer replay work.

Reproduce the final deterministic laboratories without altering historical receipts:

```sh
npm run benchmark:pr198:check
npm run benchmark:pr198:replay
npm run benchmark:pr198:source-replay
npm run benchmark:pr198:source-replay -- --case=receptions
npm run benchmark:pr198:source-replay -- --case=opportunities
npm run benchmark:pr198:source-replay -- --case=disruption
```

To conduct a new full development cohort, supply a fresh version; existing receipts are preserved:

```sh
npm run benchmark:pr198:matches -- --version=new-development-v1 --workers=3
```

The common match flags include all three PR197 experiments and the PR194 research flags. Canonical arrival is independently false. Corrected adds only receiver synchronisation (dependent on receiver anticipation) and the observed loft repertoire. Both remain absent by default in normal play. Direct family control/retention requires the direct-touch path; full-match control/retention can include an intervening deflection and is explicitly labelled separately.

There is no duplicate full-tick archive. Compact event/body witnesses and full-stream hashes are retained; exact-source reconstruction regenerates the physical streams. Conditional meeting error on thirteen common contacts improves, while failed contacts remain in the full denominator. Missing capabilities and uncalibrated value are recorded as open issues, not supplied by fabricated rebounds, possession or restarts.
