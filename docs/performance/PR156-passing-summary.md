# PR156 ability × difficulty matrices

Each cell uses 64 paired samples, with receiving attributes fixed at 60. The four technical passing attributes move together. A clean-control count can occur on a subsequently unsuccessful delivery; completion and open-play secure retention are separate metrics. Execution error describes the sampled launch-objective displacement, not integrated landing error. See the main PR156 report for physical measurement definitions and limitations.
