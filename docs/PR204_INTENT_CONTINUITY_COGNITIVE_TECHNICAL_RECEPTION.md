## Gate B: development intervention

`two-pass-continuity-dev-v1` is an explicit development switch in the existing state/store, not a profile or default. ### Development factorial: fixed released-ball continuations

This is a bounded development study, **not evidence that advance game reading compensates for weak technique**. The inherited PR201 released-ball fixtures generated 60 launches (five named pass families × two sample geometries × three factors × editions 200/201), 20 distinct seed labels, and four continuations per launch. The three factors reuse each seed; the independent seed count is therefore 20 rather than 60 or 240. Within each quartet the physical ball, initial player bodies, environment and all other attributes are identical. After the launch, the named receiver's `gameReading`/`firstTouch` are set to 20/20, 20/85, 85/20 or 85/85 and each arm runs the ordinary 40 Hz canonical continuation with the PR201 `hold-local-v1` recovery enabled. The laboratory asserts the ball hash is unchanged at continuation start. Later physical trajectories can diverge naturally. No outcome quota, artificial reach or new success bonus is applied.

The intervention is **after** release: the original launch and its precomputed receiver plan were generated with baseline attributes, not each factorial combination. The experiment thus tests downstream continuation under paired skill interventions; it does not establish a pre-release recognition or anticipatory movement effect. `firstDisplacement` may reflect existing velocity and is not a recognition or voluntary preparation timestamp. These fixtures do not systematically cross adequate versus inadequate preparatory windows or cover every requested family, first-time redirection, pressure timing or late physical deviation. The 60 episodes are clustered around only 20 seeds and a small set of fixture geometries. All 240 arms run the same real ball per quartet, not the same ball across different quartets.
