# PR171 browser evidence and reference attribution

Screenshots come from the local production build of MFL used in the PR171 audit.
`career-human-pass.png` shows hidden advancement after a real human pass;
`career-result.png` and `career-reloaded.png` show the saved hybrid result.
`lab-3d.png` verifies actual WebGL stadium/player rendering; `lab-export.png`
records the developer session export controls. The downloaded export's SHA256
and the scope of each check are in `../../performance/PR171-browser.json`.
