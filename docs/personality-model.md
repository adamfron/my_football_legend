# Jedna osobowość zawodnika

Planowany kwestionariusz twórcy postaci nie może tworzyć drugiego systemu osobowości.
Odpowiedzi mają modyfikować te same parametry wykorzystywane przez symulację i wydarzenia:
`determination`, `ambition`, `professionalism`, `matchEffortTendency` oraz
`trainingEffortTendency`. Archetyp pozostaje wejściem do istniejącego modelu zachowania,
a nie równoległą etykietą bez wpływu na karierę.
