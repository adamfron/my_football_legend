# Formation geometry and attacking-funnel benchmark

The benchmark uses the canonical spectator engine at its native 25 ms step. It creates a legal native formation directly, without a manager selecting a different starting XI. The default anchor is 4-4-2; opponents are 4-3-3, 4-2-3-1, 4-4-2, 3-4-2-1 and 3-5-2.

Every attribute is 50 in the primary experiment. Auxiliary conditions are also identical: age 25, height 180 cm, weight 75 kg, hidden attributes 50, full position familiarity, condition 100, no injury, neutral manager/club effects, identical explicit tactical preferences and genuine eight-player benches. Equal preferred-foot profiles and full weak-foot familiarity remove an accidental lateral ability difference. Native slot duties are retained; `--normalise-duties` provides a separate diagnostic experiment. The fixture records full profiles and effective XI strength, rather than trusting a club headline OVR.

Logical player IDs belong to the anchor/opponent and remain stable when the sides reverse. Each call constructs fresh mutable profiles. Home still takes the first kickoff through existing canonical initialisation; reversal controls that exposure instead of silently altering kickoff rules.

```sh
npm run benchmark:formation-geometry -- --seed-count=3 --traces --output=docs/performance/pilot.json
npm run benchmark:formation-geometry -- --seed-count=12 --traces --output=docs/performance/main.json
npm run benchmark:formation-geometry -- --seed-count=12 --traces --output=docs/performance/main.json --resume
npm run benchmark:formation-geometry -- --anchor=4-3-3 --opponents=4-4-2,3-5-2 --attributes=80 --opponent-attributes=60 --seeds=my-seed-1,my-seed-2
npm run benchmark:formation-geometry -- --mode=clubs --seeds=lab-mv2ymq0c,pr162-1,pr162-2 --traces
npm run benchmark:formation-geometry -- --engine-root=../pr162-baseline --revision=4d61ee8e0214bd230b27bbbc41a7b7024411afd8 --mode=baseline
```

All arguments use `--key=value`, except boolean flags. Additional controls: `--minutes` (90 by default), `--style`, `--normalise-duties`, `--no-observer`, `--output` and `--engine-root`. The latter imports canonical simulation, ranking, shooting availability and opportunity evaluation from the selected checkout. It never substitutes a simplified engine. At 90 minutes the native whistle owns termination and halftime is advanced canonically. A 7,200-second safety ceiling marks an unfinished game as censored; it does not fabricate a final whistle or score. Other durations explicitly use fixed observation windows.

A pilot comprises 5 matchups × 3 seeds × 2 orientations = 30 matches. A main matrix comprises 5 × 12 × 2 = 120. These long experiments are opt-in and are not part of normal CI. Running the five formations in disjoint CLI shards is supported by the summary module, which verifies manifests and rejects duplicated match keys. Checkpoints are written atomically after every match. Resume rejects changed sources, Node version, configuration or benchmark implementation. It does not silently extend a seed list or reuse data measured against another engine.

The manifest stores Git revision, SHA-256 over all non-test core/schema/type sources, SHA-256 over the runner/fixture/funnel implementation, telemetry version, Node version, fixed step and configuration. Every match stores fixture and complete initial/final state hashes. Profiles are deduplicated by hash. Source files are rechecked at every checkpoint, so editing canonical code during a run fails explicitly. The frozen baseline records the pristine PR161 revision. Historical exports lacking a revision remain observations, not claimed exact replay fixtures. Disjoint seed extensions can be joined with `joinBenchmarkSeedBlocks` only when the entire remaining manifest matches. Changed physics, duties, abilities or observer protocols are rejected, as are overlapping seed blocks.

## Measurement definitions

Controlled possession begins only when an actual active player controls the ball. A flight or loose-ball claim cannot start one. Same-team deliveries retain the team sequence; opposing control or a stoppage ends it. Unique possession stages are counted once, while repeated entries have separate event counts. Final-third entry requires controlled depth ≥70 m; sustained presence requires two cumulative controlled seconds. Box entry requires depth ≥88.5 m and the 40.32 m penalty-area width. A credible shooting position uses the existing opportunity category, not a shot quota.

Progressive release/completion requires >5 m attacking-direction gain from the ball position in the preceding canonical tick, at most 0.025 s before the observed release. Backward release requires <-2 m; the remaining deliveries are lateral. This is an explicitly quantised observer origin, not a separately persisted launch-contact coordinate. Completions and role edges use the actual receiver and physical contact point. V2/V3 also record an onside receiver subsequently receiving >1 m beyond the defensive/offside line captured in that preceding tick. This is a specific last-line reception measure, not every tactical midfield line break. V1 baseline's `progressive_reception` meant receiver displacement during flight; it must not be compared with the corrected V2/V3 stage or treated as a missing zero.

Action rankings are sampled at most once per two seconds for controlled owners whose action cooldown is zero. Availability, physical executability, ranking and actual release remain separate. Samples do not enumerate every decision. The pure ranking uses independently seeded diagnostic noise and cannot advance canonical RNG. Decision/possession traces are capped at 32; representative spatial samples at 24. Totals and online spatial moments continue after the caps. No per-tick trajectory archive is committed.

V3 deduplicates both in-flight and settled canonical shot identities before closing an attack at a stoppage, and separately records settled outcomes/rebound sources. The executable-shot conditional numerator is the intersection of first-ranked and physically executable sampled shots, including headers. A first-ranked sampled option is not claimed to be a canonical selection. V1/V2 settled-shot records cannot reliably supply possession-level shot conversions: their invalid joint stages are removed and conversions set to `null` in the historical compact evidence, while original canonical shot totals remain valid. The final formation experiment is measured entirely with V3. Set-piece shots without an open-play controlled sequence remain canonical shots, outside those sequence-conditioned denominators.

Width/depth, individual position moments, anchor/target distance and striker distance from the live line use real bodies every ten seconds. Positions are transformed into the team's attacking direction. Whole-match statistics supply passing, shots, saves, corners, possession, tackles, fouls, substitutions and workload. Foul-zone tables cover observed ground challenges, not every canonical foul source. The 360-degree low-progress observer integrates facing changes within a continuous control episode; it reports duration, not an invented count of tactical pirouettes.

For each seed, the anchor-minus-opponent difference is calculated for both orientations and averaged. The two matches are one seed block. The report supplies raw orientations, mean, median, sample standard deviation, all block values and exploratory Student-t intervals. Censored fixtures remain in the raw evidence but are excluded from full-match W/D/L and full seed-pair comparisons. The intervals are exploratory and unadjusted across five comparisons. The equal 4-4-2 self-match records a nonzero logical-identity signal after reversal (paired shots −0.38, 95% interval [−0.61, −0.14]); that unresolved asymmetry prevents treating these sparse outcomes as a formation ranking.

## Evidence and remaining coverage

See [the audit](PR162_INTEGRATED_MATCH_REALISM_AUDIT.md), [ten canonical evidence tables](performance/PR162-EVIDENCE_TABLES.md) and [machine-readable summary](performance/PR162-summary.json). Missing advanced counters are disclosed explicitly. The complete main experiment is 120/120 full matches: the unchanged 30-match pilot plus 90 disjoint extension matches, all at frozen source `86673d5fe3752efc6008cbd56b4e9ed048faafda`, V3. Use that checkout when reproducing the published matrix. The subsequent physical-origin schema patch is a separate source, with two-full-match complete-state parity in PR162-schema-parity.json; its samples are never pooled into that matrix. Broader attribute sweeps and all-versus-all matrices are configurable, not automatically launched.

Focused tests cover legal XIs, mirrored identity, fresh profiles, observer/state parity, unique versus repeated stages, unowned loose balls, depth compensation, physical readiness, fatigue projection and physical boundary contacts. Full long-match observer parity is additionally stored in the performance evidence. Normal `npm run verify` remains the acceptance gate for implementation; a green gate does not itself prove realistic football statistics.

Public evidence under docs/performance is reduced to numerical summaries and provenance/validation receipts. Full profiles, initial frozen states and bounded traces remain in a complete local archive (see PR162-DATA_README.md). Run `scripts/summarizePr162.ts --main --source=<shard-directory> --archive-dir=<local-directory>` with the TypeScript loader to rebuild reports and compact full records. `scripts/replayPr162Restart.ts --archive=<restart-states.json.gz>` validates complete frozen state and SHA before replay. `scripts/checkPr162SchemaParity.ts` runs the two canonical full-state source-parity matches.
